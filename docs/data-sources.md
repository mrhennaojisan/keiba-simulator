# データ取得元と利用上の注意

- 外部サイトのデータ取得は `backend/keiba_core.py` 内の取得関数にまとまっており、予想ロジックとは分離しています
- **事前計算方式**のため、外部サイトへのアクセス数は利用者数に比例しません
- 各サイトの利用規約はサービスごとに異なり、自動取得や再配布を制限している場合があります。公開・商用利用の前に必ず確認してください（本書は法的助言ではありません）
- 規約上の懸念がある場合の方針:
  1. 取得アダプタを無効にし、**手入力モード**（`/api/manual`）だけで運用する（外部依存ゼロ）
  2. 利用が許可されたデータ源（公式API・自作データ・ライセンスのあるデータ）に差し替える
- 外部取得を一切行わない入力専用のColab版も別途用意しています
